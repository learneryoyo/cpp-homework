## 目录约定

作业不多的时候，**一个作业一个 .cpp 文件，直接放在根目录**，命名用 `第N次上机.cpp`：

```
作业/
├─ 第一次上机.cpp
├─ 第二次上机.cpp
└─ ...
```

如果某次作业需要交多个文件（比如 `.h` + `.cpp`，或者带 Word 报告），那就建一个文件夹装起来：

```
作业/
└─ 第三次上机/
   ├─ 第三次上机.cpp
   ├─ main.h
   └─ 实验报告.docx
```

**不要提交的东西**（`.gitignore` 已经自动忽略）：
编译出来的 `*.exe`、`*.o`、`*.obj`，以及 `.vscode/` 配置文件夹。
交源码就够了，可执行文件每次编译都能重新生成。
