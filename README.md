## 目录约定

**每次上机 = 一个文件夹；每道题 = 一个 `.cpp` 文件。**

文件名格式：`两位序号_英文短描述.cpp`

```
作业/
├─ 第一次上机/
│  ├─ README.md                    ← 本次作业的题目索引
│  ├─ PROMPT_LOG.md                ← AI 使用记录（课程要求）
│  ├─ 01_bonus_by_profit.cpp
│  ├─ 02_grade_by_score.cpp
│  ├─ 03_palindrome_number.cpp
│  ├─ 04_armstrong_number.cpp
│  ├─ 05_repeated_digit_sum.cpp
│  ├─ 06_multiplication_table.cpp
│  ├─ 07_fibonacci_rabbits.cpp
│  └─ 08_monkey_peaches.cpp
└─ 第二次上机/
   └─ ...
```

**为什么一题一个文件？**

C++ 里一个程序只能有一个 `main()`。把 8 道题塞进同一个 `.cpp`，除了最后一道，其余 7 道都得注释掉才能编译——这就是之前那个文件的写法。拆开之后：

- 每道题都能单独编译、单独运行、单独调试
- 哪道题报错，一眼定位到文件，不用在几百行注释里翻找
- 改某道题不会牵连其他题

**不要提交的东西**（`.gitignore` 已自动忽略）：编译产物 `*.exe`、`*.o`、`*.obj`，以及 `.vscode/` 配置文件夹。

## 快速提交

双击根目录的 **`提交作业.bat`**，自动完成 `add → commit → push`。

也可以带一句提交说明（不写就自动用「日期 + 时间」）：

```
提交作业.bat "第一次上机 8题"
```

详细步骤和常见报错处理见 **[提交指南.md](./提交指南.md)**。
