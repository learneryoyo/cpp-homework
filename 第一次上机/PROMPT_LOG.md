## 记录 3｜01 题：条件判断恒真的 Bug

- **场景**：找 Bug 思路
- **触发方式**：**AI 主动指出**（我并没有专门提问，是在拆分完成后 AI 顺带提醒的）
- **问题**：我原来写的是

  ```cpp
  if (0 < profit <= 100000)
  ```

  C++ 里关系运算符从左往右结合，先算 `0 < profit` 得到一个 `bool`（真为 1，假为 0），
  再拿这个 0 或 1 去和 100000 比较，**结果永远为真**。所以不管输入多少利润，都只进第一个分支。
- **AI 给的改法**：

  ```cpp
  if (profit > 0 && profit <= 100000)
  ```

- **我的验证**：输入 `150000`，修改前输出 `10000`（错），修改后输出 `13750`（对，= 100000×0.1 + 50000×0.075）。
- **我的理解**：这类错误编译器**不会报错**，因为语法完全合法，只是语义和我想的不一样。以后写区间判断一律用 `&&` 连接两个比较。
- **是否采纳**：采纳。

## 记录 4｜03 题：回文数算法逻辑错误

- **场景**：找 Bug 思路
- **触发方式**：**AI 主动指出**。AI 在跑用例时发现输入 `12345` 竟然输出「是回文数」，于是回头查了我的算法。
- **我原来的写法**：

  ```cpp
  int s = 1;
  while (num >= 10) {
      temp += (num % 10) * s;
      num /= 10;
      s *= 10;
  }
  temp += (num) * s;
  ```

- **问题**：每次把取出的个位放到**越来越大**的权重上，重建出来的其实是**原数本身**，不是逆序数。
  以 `12345` 为例：

  | 步骤 | 取出的位 | 权重 s | temp 累加后 |
  | :-- | :--: | :--: | :--: |
  | 1 | 5 | 1 | 5 |
  | 2 | 4 | 10 | 45 |
  | 3 | 3 | 100 | 345 |
  | 4 | 2 | 1000 | 2345 |
  | 5 | 1 | 10000 | **12345** |

  算出来还是 12345，和原数相等 → 任何数都会被判成回文。
- **AI 给的改法**：

  ```cpp
  int temp = 0;
  while (num > 0) {
      temp = temp * 10 + num % 10;
      num /= 10;
  }
  ```

- **我的理解（手算核对过）**：每取出一位，先把已有结果整体左移一位（×10），再把新位塞到个位：

  | 步骤 | num | num % 10 | temp |
  | :-- | :--: | :--: | :--: |
  | 初始 | 12345 | — | 0 |
  | 1 | 1234 | 5 | 5 |
  | 2 | 123 | 4 | 54 |
  | 3 | 12 | 3 | 543 |
  | 4 | 1 | 2 | 5432 |
  | 5 | 0 | 1 | **54321** |

  54321 ≠ 12345 → 不是回文，正确。
- **我的验证**：`12321` → palindrome，`12345` → not a palindrome，`7` → palindrome，`1001` → palindrome，`1230` → not a palindrome，5 个用例全对。
- **是否采纳**：采纳。
- **需要说明的一点**：这一处 AI 给出的是完整的循环体写法，不是我独立想出来的。
  我把它拆成表格逐步手算了一遍，确认每一步的 `temp` 值都对，现在能自己默写出来。

## 教师抽查访谈 · 我能当面讲清的三个问题

1. **为什么 `0 < profit <= 100000` 恒为真？**
   → 关系运算符左结合，先算 `0 < profit` 得到 `bool`，再与 100000 比较；`bool` 会隐式转成 0 或 1，永远 ≤ 100000。

2. **`temp = temp * 10 + num % 10` 为什么能反转数字？**
   → 每轮先把已有结果整体左移一位（×10），再把当前最低位塞到个位，相当于从低位往高位依次「推」进结果里。

3. **为什么一个 `.cpp` 里只能有一个 `main()`？**
   → `main` 是程序入口，链接阶段一个可执行文件只能有一个入口符号；多个 `main` 会报 `multiple definition of 'main'`。
